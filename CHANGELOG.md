# Changelog

## 0.1.0 – 07.10.2026

První veřejná verze.

- Lustrace přes webovou službu ISIR_CUZK_WS2 (IČO, RČ, jméno, spisová značka).
- Detail řízení a události oddílů A/B/C/D/P z veřejné HTML stránky včetně stránkování.
- Stažení PDF, textová vrstva, OCR skenů (Tesseract), rozbalení PDF portfolií.
- Fulltext napříč dokumenty řízení.
- Tok událostí rejstříku (ISIR_PUBLIC_WS).
- Balíček `.mcpb` pro instalaci do Claude Desktop jedním kliknutím (runtime uv, nastavení přes UI).
- Omezovač požadavků pod limity Podmínek provozu ISIR (40/min, 2500/den), perzistentní denní počítadlo.
